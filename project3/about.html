About Embodied Time

A Martha Graham Inspired Clock

PROGRAM NOTES

Embodied Time is a browser-based clock inspired by the movement language of modern dance pioneer Martha Graham. Instead of using numbers to tell time, this clock invites viewers to experience time through the body, movement, and performance. My goal was to transform the traditional clock into something more expressive by asking the viewer to read time the way an audience reads a dance performance.

Inspiration

I have always admired Martha Graham's work because of the way she communicates emotion through movement. Her technique demonstrates that the body can express ideas and tell stories without relying on words. I wanted to use that same philosophy to represent something we experience every day: time.

HOW TO READ THE CLOCK

The clock is made up of three layers that work together to represent time.

Hours

Each hour is represented by one of Martha Graham signature nineteen poses. As the hour changes, the pose changes as well, replacing the traditional numbers found on a clock. The body becomes the way of measuring the passage of hours.

Fabric

The purple fabric below the pose image references Graham's iconic solo Lamentation. Throughout the minute, the fabric is gradually revealed, creating a second visual layer that reflects the continuous flow of time. Unlike the hour, which changes suddenly, the fabric changes gradually, emphasizing that time is always moving.

Movement Vocabulary

Words such as Contraction, Release, Spiral, Fall, Recovery, and Suspension appear and fade throughout the experience. These are some of the fundamental principles of Martha Graham's technique. Their changing rhythm echoes the breath, emotion, and physicality that define her choreography.

TECHNICAL CREADITS

This project was created using HTML, CSS, and JavaScript. JavaScript's Date Object retrieves the current hour and updates the illustrated pose accordingly. The movement vocabulary changes every ten seconds using setInterval(), while CSS animations create the slow fade-in and fade-out effect for each word. CSS was also used to create the theatrical stage layout and position each visual element. Pictures are from Martha Graham wesbite and the concept and design by Rubi Perez Guzman
